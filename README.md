### Featured project

**[India Air Quality Lakehouse](https://github.com/Guru2497/india-air-lakehouse)** turns hourly air pollution data for 10 Indian cities into India's official National AQI, following CPCB rules. PySpark and Delta Lake in a Bronze / Silver / Gold layout, with idempotent `MERGE` upserts, late-arriving data handling, data quality gates, 40+ tests and CI. It runs every morning and publishes [today's AQI table](https://github.com/Guru2497/india-air-lakehouse/blob/main/LATEST_AQI.md).
